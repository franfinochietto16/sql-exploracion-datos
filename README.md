Exploración inicial con SQL en Data Science
Este repositorio contiene una práctica de extracción y manipulación de datos simulando el proceso de exploración que realiza un Data Scientist antes de modelar.
El script de Python utiliza la librería sqlite3 para ejecutar consultas SQL sobre un DataFrame en memoria.

Consultas realizadas:
Selección Simple: Extracción de productos y precios con ordenamiento alfabético (ORDER BY).

Filtrado Crítico: Búsqueda de ventas de alto valor en países específicos mediante múltiples condiciones lógicas (WHERE, AND).

Búsqueda de Nulos: Identificación de problemas de calidad de datos (IS NULL).

Análisis de Rendimiento: Agrupación y cálculo de métricas financieras usando funciones de agregación y alias (SUM, GROUP BY, AS).

Filtro de Élite: Filtrado de resultados posterior a la agregación para encontrar categorías de alto rendimiento (HAVING).
